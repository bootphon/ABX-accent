# Data Evaluation

After preparing the dataset (see the [preparation section](https://github.com/bootphon/ABX-accent/tree/main/abx-accent/data/prepare)), the next step is to evaluate the data. The evaluation process involves the following steps:

* **Item files**: Required input files for the ABXpy evaluation.


* **ABXpy tasks**: Scores are generated for both *within-speaker* and *across-speaker* tasks.
* **Average scores**: The average ABX score is computed for each accent in each dataset split (dev/test).
